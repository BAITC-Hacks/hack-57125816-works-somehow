# Іріктеу — іс-шараға маман немесе орын таңдау

Қазақша шағын веб-қосымша. Қала, күн, іс-шара түрі, санат және бюджет бойынша нақты каталогтан **ең көбі 3 профиль** ұсынады. Тіл мен ұзақтықты қосымша таңдауға болады. Әр карточкада аты, санаты, қаласы, бастапқы бағасы, деректерден алынған ерекшелігі және сәйкестік түсіндірмесі бар.

**API кілті, тіркелу, төлем және брондау қажет емес.** Қосымша Python 3.9 немесе жаңарақ нұсқамен жұмыс істейді. Сыртқы Python/JavaScript кітапханаларын орнату, `pip install` немесе `npm install` қажет емес. Іске қосылған соң интернетсіз жұмыс істейді.

## Mac-та іске қосу: ретімен

1. Пернетақтада **Command + Space** басыңыз, `Terminal` деп жазыңыз, **Enter** басыңыз.
2. Терминалға мына команданы көшіріп, **Enter** басыңыз. Тырнақшаларды сақтаңыз: қалта атауында бос орын бар.

   ```bash
   cd "$HOME/Downloads/Новая папка"
   ```

3. Python бар екенін тексеріңіз:

   ```bash
   python3 --version
   ```

   `Python 3.9` немесе одан жоғары нұсқа жеткілікті. Осы Mac-та `Python 3.9.6` арқылы тексерілді. Егер команда табылмаса, [Python ресми сайтынан](https://www.python.org/downloads/macos/) Python 3 орнатып, Terminal-ды қайта ашыңыз.

4. Серверді іске қосыңыз:

   ```bash
   python3 event-match/server.py
   ```

5. Терминалда `Дайын: http://127.0.0.1:8000` пайда болады. **Терминалды ашық қалдырыңыз.** Safari немесе Chrome ашып, мекенжай жолағына жазыңыз:

   ```text
   http://127.0.0.1:8000
   ```

6. Қажетті өрістерді өзгертіп, **«Сәйкес профильдерді табу»** батырмасын басыңыз. Бастапқы мысал автоматты көрсетіледі. «Жүргізуші», «Флорист», «Бос нәтиже» батырмалары дайын мысалдарды ашады.
7. Тоқтату үшін Terminal терезесіне оралып, **Control + C** басыңыз.

Егер `8000` порты бос болмаса:

```bash
python3 event-match/server.py --port 8001
```

Сонда браузерде `http://127.0.0.1:8001` ашыңыз. HTML файлын екі рет шертіп ашу жеткіліксіз: іріктеу үшін жергілікті Python сервері керек. Қалта басқа жерге көшірілсе, 2-қадамдағы жолды өзгертіңіз; бастапқы CSV мен `event-match` қалтасы қатар тұруы керек.

## Нақты кіріс файлдары

Алдымен берілген DOCX тапсырмасы, CSV және HTML каталогы оқылды. Бастапқы үш файл өзгертілмеді және өшірілмеді. Бұрын дайын қолданба коды болмаған; `hackathon dataset preview.html` тек каталог көрінісі болған. Жаңа код `event-match/` ішінде.

Дереккөзі — **`hackathon dataset anonymized .csv`** (атауда `.csv` алдында бос орын бар). Әр іске қосқанда осы файл тікелей оқылады; ойдан профиль, баға немесе бос күн қосылмайды.

Нақты файлда **66 профиль, 13 баған, 17 санат** бар. Бір профиль бірнеше санатқа жатуы мүмкін. Қала мәндері: Алматы — 50, Астана — 15, `Зарубежье` — 1 (интерфейсте «Шетел», нақты қала емес).

| CSV бағаны | Оқылуы / қолданылуы |
|---|---|
| `id`, `anon_name` | Бірегей идентификатор, жасырындандырылған есім |
| `categories` | `\|` арқылы бөлінген санаттар; дәл сәйкестік |
| `city` | Қала/аймақ; дәл сәйкестік |
| `price_from_kzt` | Іс-шараға бастапқы баға, бүтін теңге |
| `event_formats` | `\|` арқылы бөлінген қабылдайтын іс-шара түрлері |
| `languages` | `\|` арқылы бөлінген жұмыс тілдері |
| `max_hours` | Алаңда болудың ең ұзақ уақыты; бос болса `None` |
| `busy_dates` | `\|` арқылы бөлінген `YYYY-MM-DD` күндері |
| `description` | Түпнұсқа сипаттама; карточканың ерекше дерегіне негіз |
| `synthetic` | `True`/`False`: 13 профиль жасанды |
| `city_imputed` | `True`/`False`: 8 профильдің қаласы дайындау кезінде толтырылған |
| `price_imputed` | `True`/`False`: 18 профильдің бағасы дайындау кезінде толтырылған |

CSV стандартты `csv.DictReader` арқылы оқылады: тырнақшадағы үтір мен көпжолды мәтін сақталады. Жалаушалар мәтіннен нақты логикалық мәндерге айналады (`"False"` ақиқат деп есептелмейді). Дұрыс емес құрылым, баға, жалауша, қайталанатын `id` немесе қате күн анықталса, сервер дерек ойлап қоспай, қатені көрсетеді.

## Іріктеу және тұрақты реттілік

1. Сұраныс серверде тексеріледі: күн **23.09.2026–31.12.2026** аралығында, бюджет — теріс емес бүтін сан, қосымша ұзақтық — оң сан. Сол күн аралығы формада да шектелген. Бос тіл/ұзақтық сүзгіге әсер етпейді.
2. Алдымен `city` және `categories` дәл сәйкес келетін үміткерлер алынады. Қазақша атаулар тек көрініс үшін; сұраныс CSV-дің түпнұсқа мәндерімен салыстырылады.
3. Әр үміткердің **барлық** шарттары тексеріледі: күн `busy_dates` ішінде жоқ; `price_from_kzt <= budget`; іс-шара түрі `event_formats` ішінде; таңдалған тіл `languages` ішінде; таңдалған ұзақтық `max_hours` шегінен аспайды.
4. **`max_hours` бос болса, ұзақтық шектеуі қолданылмайды.** Бұл 9 профильге қатысты: флорист, безендіруші және сыйлық қызметтері. Олардың күні, бағасы, форматы және тілі бәрібір тексеріледі. Орындар мен мамандарға бос емес күннің ережесі бірдей.
5. Өткен профильдер **`(price_from_kzt, id)` өсу ретімен** реттеледі. `id` — мәтін ретінде салыстырылады; осы каталогта барлық `HK-` нөмірі бес таңбалы. Алғашқы 3-еуі көрсетіледі. Мысалы, бағасы тең `HK-23752` әрқашан `HK-83709` алдында тұрады.

Кездейсоқтық, жүйенің ағымдағы күні, CSV жолдарының реті және AI реттілікке әсер етпейді. Бір CSV және бір сұраныс әрқашан бірдей нәтиже береді. Бағасы төмен нұсқалар алдымен шығады; бұл сапа рейтингі емес. `imputed`/`synthetic` белгілері профильдерді автоматты алып тастамайды, бірақ әр карточкада **иә/жоқ** түрінде ашық көрсетіледі.

Үш нәтиже бөлек беріледі:

- **Сәйкес профильдер табылды.** Үміткер, өткен және көрсетілген профиль саны бар. Үшеуден аз болса, каталогтың өзі шағын ба, әлде шарттардан өтпегендер бар ма — түсіндіріледі.
- **Бұл қалада мұндай санат жоқ.** Қала+санат жұбы бойынша нөл үміткер.
- **Профильдер бар, бірақ шарттардан өтпеді.** Бос емес күн, бюджет, формат, тіл, ұзақтық бойынша нақты сандар және әр профильдің себебі беріледі.

Бір профиль бірнеше себеппен өтпеуі мүмкін. Сондықтан себептердегі сандар қосындысы өтпеген профильдер санынан артық болуы мүмкін; интерфейс мұны түсіндіреді. Сипаттама мәтіні құрылымдалған `event_formats`/`languages` өрістерін кеңейтпейді.

## Түсіндірмелер және AI

**Осы нұсқада сыртқы AI API қолданылмайды.** Интернет не AI қызметі істемесе де негізгі іріктеу мен түсіндірме жұмысын жалғастырады. API кілтінің айнымалысы да талап етілмейді.

Карточканың бірінші сөйлемі — нақты `description` ішіндегі ерекшеліктің алдын ала дайындалған қазақша мазмұны. `profile_facts.json` әр `id` үшін қазақша `kk` мәтіні мен дәл көшірілген `source` үзіндісін сақтайды. Сервер үзіндінің CSV сипаттамасында бар екенін тексереді. «Түпнұсқа дерегі» бөлімінен оны ашуға болады. Екінші сөйлем — бюджет, формат, күн және таңдалған тіл/ұзақтықтың нақты сәйкестігі. Профильдің өз мәлімдемесі тәуелсіз расталған факт ретінде ұсынылмайды.

Мысалы, бір жүргізушінің DJ мен мультимедиа жабдығы, екіншісінің 13 жылдық той тәжірибесі, үшіншісінің тележүргізушілік тәжірибесі көрсетіледі. Жалпылама «тамаша таңдау» сөзі қолданылмайды. Түпнұсқа дәйексөз орысша (кейде атаулар ағылшынша); интерфейс пен негізгі түсіндірме қазақша.

AI кейін қосылса, оның орны — **іріктеу мен реттілік толық бекітілгеннен кейінгі мәтінді өңдеу қабаты**. Оған тек таңдалған карточкалардың деректері берілуі керек. AI профильді, `id`-ны, бағаны, күнді, жалаушаны немесе карточка ретін өзгерте алмайды. Қате, уақыттың бітуі, белгісіз мәлімет немесе жарамсыз жауап болса, осы жергілікті түсіндірме сақталуы керек. Бұл болашақ кеңейтудің шарты; қазір AI интеграциясы жоқ.

Құпия кілтті кодқа, браузер JavaScript-іне немесе GitHub-қа жазбаңыз. Қосылатын кілт тек сервер ортасынан оқылуы керек; `.env`, `.env.*`, виртуалды орта және Python кэші `.gitignore` ішінде. `.gitignore` бұрын Git-ке қосылған құпияны автоматты жоймайды.

## Тексеру

Сервер ашық тұрса, **Command + T** арқылы Terminal-да жаңа қойынды ашып, жоба қалтасына өтіңіз. Тесттерді орындаңыз:

```bash
cd "$HOME/Downloads/Новая папка"
python3 -m unittest discover -s event-match/tests -v
```

Тесттер нақты CSV-ді пайдаланады: үш нәтиже түрі, busy күндер (барлық 100 күн), орындар, тіл, бюджет/ұзақтық шекаралары, бос `max_hours`, тең бағалар, күн ауысуы, қайталау, CSV жолдарын араластыру, дәйексөздер, жалаушалар, жарамсыз сұраныс және HTTP маршруттары тексеріледі. HTTP тесті өз уақытша жергілікті портын ашады, негізгі серверді алдын ала іске қосу қажет емес. Сәтті аяқталса, соңында **`OK`** шығады.

Нақты деректерге арналған қысқа демоны орындау:

```bash
python3 event-match/examples.py
```

Төмендегі мысалдардың бәрінде, өзгеше көрсетілмесе: **Алматы, Үйлену тойы, 2 000 000 теңге**, тіл мен ұзақтық бос.

| Мысал | Санат / күн / өзгеріс | Күтілетін карточкалар реті |
|---|---|---|
| Көп профиль | Жүргізуші, 23.09.2026 | `HK-44923`, `HK-42352`, `HK-27222`; 10 үміткердің 4-еуі өтеді, 3-еуі көрсетіледі |
| Басқа күн | Сол сұраныс, 24.09.2026 | `HK-35215`, `HK-72938`; 2 профиль өтеді |

| Бос емес күн | Флорист, 25.09.2026, 12 сағат | Екеуі де бос емес; карточка жоқ |

## Файлдар және шектеулер

```text
Новая папка/
├── [бастапқы DOCX, CSV, HTML — сақталған]
├── README.md
└── event-match/
    ├── server.py          # Жергілікті HTTP сервері; тек рұқсат етілген маршруттар
    ├── catalog.py         # CSV, түрлендіру, қазақша атаулар, деректі тексеру
    ├── matching.py        # Іріктеу, реттілік, себептер және түсіндірмелер
    ├── profile_facts.json # 66 профильдің ерекшелігі және дәлел үзінділері
    ├── examples.py        # Нақты деректер бойынша 8 мысал
    ├── dist/             # Қазақша HTML, CSS және JavaScript
    └── tests/            # Іріктеу және HTTP тесттері
```

- Бастапқы баға соңғы баға емес: **«… теңгеден бастап»**. Бюджет тек осы мәнмен салыстырылады; жеңілдік, жолақы немесе сағаттық қосымша төлем есептелмейді.
- Күнтізбе тек берілген 100 күнді қамтиды. Бос емес деп белгіленбеген күн нақты брондау мүмкіндігіне кепілдік бермейді.
- Аты-жөндер жасырындандырылған, 13 профиль жасанды. Қала/бағасы толтырылған жазбалар арнайы белгіленеді.
- Кей сипаттамалар қысқа: қосымша тәжірибе не артықшылық ойдан қосылмайды. Аудармалар қолмен дайындалған; дәлелдің бар-жоғы автоматты тексерілгенімен, мағына дәлдігін адам қарайды.
- CSV өзгерсе, серверді қайта іске қосыңыз. Профильдер не сипаттамалар өзгерсе, `profile_facts.json` дәлелдерін де тексеріп жаңартыңыз. Танылмаған санат/тіл/қала үшін қазақша атауды `catalog.py` ішіне қосу керек.
- Бұл Mac-тағы жергілікті демонстрация: `127.0.0.1` арқылы ғана тыңдайды, интернетке жарияланбаған. Өндірістік хостинг, тіркелу, төлем, брондау және хабарлама жіберу жасалмаған.
