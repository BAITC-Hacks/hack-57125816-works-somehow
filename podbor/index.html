КАЖДЫЙ ВЫБОР МОЖНО ПРОВЕРИТЬ

Подборка с понятными причинами.

Все профили проходят одинаковые проверки. Цены, свободные даты и достижения не придумываются.

01 / ПРОВЕРКА

Учитываем каждое условие.

Город, категория, занятость, бюджет, тип события, выбранный язык и длительность. Пустой лимит длительности означает, что время на площадке не применяется.

02 / ПОРЯДОК

Сохраняем стабильный результат.

Подходящие профили сортируются по начальной цене, затем по id. Показываются первые три. Одинаковый запрос всегда возвращает тот же порядок.

03 / ОБЪЯСНЕНИЕ

Показываем факты из каталога.

В каждом объяснении есть особенность профиля и проверенные условия. Внешний ИИ не используется. Подбор полностью работает без интернета.

Открыто говорим о качестве данных.

syntheticПрофиль искусственно создан для набора данных.

city_imputedГород заполнен при подготовке набора данных.

price_imputedЦена заполнена при подготовке набора данных.
